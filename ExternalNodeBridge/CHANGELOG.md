# Changelog

## 0.2.0

- 外部节点通过 XBoard 原生模板分组，保留各客户端协议字段，校验节点替换完整性并提供失败回退。
- 上游账户支持兼容 API 检测、登录、套餐查询、订阅地址同步和 Telegram 通知。
- 提供手动、定期及授权组用户到期轮换，记录重置意图，支持中断后查询恢复。
- 安全验证与访问阻拦会暂停账户操作；轮换未确认时停止下发对应来源。
- 缓存区分无兼容节点、转换失败和网络故障，待刷新状态随输出格式配置保持一致。
- 管理控制台提供来源和账户编辑、分步保存结果、部署自检、资源修复及脱敏诊断。
- 公开资源随插件生命周期管理，私有设置、缓存和凭据独立加密持久化。
- 检查运行组件接口并记录进程编号，帮助识别升级后未重启的常驻进程。
- 配置界面采用 XBoard 原生模板与统一字段，保留必要的配置兼容检查；发布入口统一为 `publish.sh`。

详细升级步骤与 0.1.1 对比见完整源码中的 `docs/releases/v0.2.0.md`。

## 0.1.1

- 原生配置弹窗自动显示可复制的完整控制台地址，无需寻找文档入口。
- 按当前后台请求生成地址，支持 HTTPS、可信反向代理、端口和站点子目录，不保存或硬编码域名。
- 使用插件服务扩展，不修改 XBoard 文件或注入前端脚本；保留原有鉴权与保存流程。
- 发布测试、PHP / Node 环境、打包及 Release 统一交给 GitHub Actions；Debian 发布端无需安装开发依赖。
- Tests 只监听 main / PR，消除标签触发的重复运行；提供仅限 v0.1.1 的安全修正入口。

## 0.1.0

- 按 XBoard 权限组聚合外部订阅，通过原有订阅入口分发。
- 独立 SubConverter-Extended 转换、定时刷新、加密缓存和失败回退。
- 11 个 XBoard 生成器与 10 个目标格式，保留节点凭据和 XHTTP 下载参数。
- 按需开放的管理员控制台，支持来源编辑、权限组复选框、保存、续期和关闭。
- 转换器版本检测、限时 Debug、脱敏诊断导出和服务器 CLI。
- 提供安装包、部署示例、迁移回退工具及回归测试。
