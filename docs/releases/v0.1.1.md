# XBoard Subscription Bridge 0.1.1

- 插件配置弹窗自动显示完整管理控制台地址，复制到浏览器即可打开。
- 地址随当前后台域名生成，处理 HTTPS、可信反向代理、端口及站点子目录；无需填写或保存域名。
- 通过后端服务扩展接入原生配置表单，不修改 XBoard 文件、不注入前端脚本。
- 保留管理员鉴权、控制台开放期限、配置保存及订阅分发行为。
- 新增源码根目录 `publish.sh`：检查 crowveil Git / GitHub 身份并发布代码、标签和 Release，支持只检查及中断后重试。

## 安装或升级

下载 `ExternalNodeBridge-0.1.1.zip`，在 XBoard 插件管理上传并按提示升级；保留已有配置。升级后重启 XBoard 的 PHP / Octane 常驻进程。

启用插件，打开「配置」，开启管理控制台并保存，复制说明中的完整地址打开。地址仅为入口，不包含登录凭据，也不会自行开放管理权限。

SHA256 校验文件 `SHA256SUMS` 对应本次发布的安装 ZIP 和源码 ZIP。
